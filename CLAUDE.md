# Farmina SA Store Training — project notes

## Current target and handoff

Static PWA for store staff at `https://apexpetgroup.co.za/training/`. The repository root is the application source; no framework or production server build is needed. Use [current status](docs/PROJECT-STATUS-2026-10-26.md) and [deployment instructions](docs/DEPLOYMENT.md) before changing or releasing it. Vercel hosting is retired; earlier Vercel notes are historical.

## Runtime map

- `index.html`, `css/styles.css`, `js/`: seven training screens, catalogue, ingredients, quiz, calculator, tips, matcher and search.
- Layout in `css/styles.css` is phone-first: base styles are the phone. The RESPONSIVE block adds touch and mouse refinements, short landscape screens (max-height 560), tablet (600+), side rail (900+ wide and 561+ tall) and labelled sidebar (1200+). `--rail`, `--nav` and each screen's `--content` drive the layout. The viewport scrolls, not `body`, so use `window.scrollTo`.
- `js/farmina-data.js`: 31 source products and the existing June 2026 price/nutrition snapshot; `js/products.js`: 36 display cards, one per product in the Shopify master `apexpetgroup-shopify/data/analysis/apex-farmina-36-product-migration-master.csv` (the approved pack-label source). Dog recipes have Mini and Medium & Maxi cards joined by `family`. `js/catalog-links.js` joins them explicitly and fails closed on changed or ambiguous identities.
- `js/feeding.js` and `assets/feeding-guides/feeding-guides.json`: 34 exact supplied feeding guides (puppy tables, adult/cat min–max ranges and the kitten table), generated by `scripts/extract-feeding-guides.py` from the PDFs and `scripts/feeding-guide-transcriptions.json` (image guides). The calculator requires a product and shows only printed guide amounts (both neighbouring printed rows for in-between weights); there is no formula estimate. The Shopify widget's separate engine does not match the printed guides yet; see `apex-feeding-engine/docs/FEEDING-GUIDE-ACCURACY-FIXES.md`.
- `js/buddy.js`: offline **Help a customer** shortlist. `js/voice-agent.js`: opt-in external ElevenLabs widget; agent prompt and data sources are configured outside this repo.
- `js/analytics.js`: consent-controlled, aggregate GA4 events for `G-6TZ2T58GQD`, gated to the production `/training/` URL.
- `manifest.json` and `service-worker.js`: scoped PWA/offline cache. `.htaccess` contains training-directory Apache rules.
- `scripts/package.py`: deterministic, root-flat cPanel ZIP in ignored `dist/`. `scripts/check-release.cjs` validates the staged release.

## Data and release rules

Product claims: Andrew Fourie, Chief Technical Officer, Apex Pet Group, is the qualified product specialist and the named source for supported claims, including "38% lower cost per day" and "most cost-effective food available in South Africa". Deon's rule from 03/11/2026: ingredient percentages are quoted only from approved sources, which are the feeding guides, the June 2026 price list and pack labels. The supplied guides print no ingredient percentages. Deon approved the Shopify master as the pack-label source on 03/11/2026.

Do not infer supplier SKUs from internal `S...` IDs, barcodes, names or pack photos. Match a current approved supplier source by supplier SKU and pack size before changing prices. Do not infer feeding guidance or veterinary suitability from a product name. The public-page pack-shot audit and its one unresolved price row are in [the price audit](docs/PRODUCT-IMAGES-PRICE-AUDIT-2026-10-26.md).

Run the four Node suites, Python package test and release checker listed in [deployment instructions](docs/DEPLOYMENT.md). Local checks do not prove the live cPanel document root, GA4 receipt, voice connection, microphone behaviour or physical-device offline use. Never extract the application at the main website root.
